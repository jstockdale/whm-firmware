## A. ARCHITECTURE VERDICTS (what is now structurally sound)
1. CAMERA: closed-form epoch engine, bidirectional-exact rebase.
   Production-proven this bench day: six rewinds, every undo exact
   to 0.01 px, seamless continuity. The integrator family (three
   generations) is deleted, not patched. No execution path feeds
   the camera, so no path can starve it. TERMINAL.
2. FOLLOWER MODEL: adopt-always. Owner keyframes are follower
   pose unconditionally; the 0.75 px threshold is diagnostics
   only. Forks bounded at one step (~0.3 px). Clones structurally
   impossible.
3. SIM PURITY: wk_step body contains ZERO per-unit reads
   (mechanically grepped: no s_w_idx, wk_i_own, esp_timer,
   s_wko). Every input is (anchor, step, shared events). The
   SHIMMY cam-pin is legal because cam is itself step-pure.
4. OWNERSHIP: 4 px handoff deadband ends the seam-flap cascade
   (flap -> gap -> silent -> storm -> respawn). Seize retains no
   deadband but is provably safe: it requires 1.2 s of owner
   SILENCE, which a live owner never yields.
5. SCROLL: five writers unified through wk_scroll_target; the
   linear 1.0x/s ramp is analytic and on the wire (type-10 rsv2,
   Q8 now|tgt) for the watch.
6. DEBT: zero TODO/FIXME/HACK markers in 15,569 lines.
7. WHLINK: verify.sh PASS standing; goldens reproduce on the
   watch side byte-for-byte; console summon works there today.
8. RAM: 33 KB standing with BLE resident, 14 KB runtime floor,
   min-ever telemetry in boot audits + status.
